
# 🔭 Example app image comparison

This is the [Streamlit example application](https://github.com/streamlit/example-app-image-comparison) refactored to run on the Federal Science DataHub using images in the FSDH Azure Blob Storage.

## Run the code locally

1. Clone the repository using `https://github.com/Sean-Stilwell/example-app-image-comparison.git`

2. Download the dependencies using `pip install -r requirements.txt`

3. Run the application using `streamlit run streamlit_app.py`

The applciation runs at `http://localhost:8501/app/ATF2` by default, this is to work on the FSDH. You can remove baseUrlPath in `./streamlit/config.toml` to remove the `/app/ATF2` base path. 

## Run the code on FSDH

1. Generate a short-term SAS token or request a long-term SAS token on the FSDH. Set it as an environment variable called `SAS_TOKEN` in your web app on the FSDH.

2. Fork the repository and update the following:
    - `baseUrlPath` in `./streamlit/config.toml`. `ATF2` should be replaced with your workspace's acronym.
    - `image` in `docker-compose.yml`. This should be updated to your repo's package. **Note:** the package is generated by GitHub Action in `.github\workflows\docker-image.yml`.

3. Ensure the images are present in your FSDH storage account.

4. Push the code and wait for the GitHub Action to build your docker image. Then, redeploy and restart the web app in the FSDH.
